# User Stories for Pongers Game

## User Story 1:
#### As a player, I want to be able to move my paddle/square using the keyboard so that I can play the game.
### Priority: **MUST**

## User Story 2:
#### As a player, I want the ball to bounce off the paddle and sides so that the game can hold a proper rally round.
### Priority: **MUST**

## User Story 3:
#### As a player, I want to gain a point every time my opponent misses the ball so that my score accumulates.
### Priority: **MUST**

## User Story 4:
#### As a player, I want to to be able to view the scoreboard as the rounds progress so that I can keep track of mine and my opponent's stats.
### Priority: **MUST**

## User Story 5:
#### As a player, I want to be able to choose from a variety of themes/designs so that I can customize my gaming experience to my liking.
### Priority: **SHOULD**

## User Story 6:
#### As a player, I want the game to conclude after a few rounds so that we reach the end result and the game doesn't drag on.
### Priority: **MUST**

## User Story 7:
#### As a player, I want there to be a final winner screen so that the winner is declared.
### Priority: **MUST**

## User Story 8:
#### As a player, I want the ball to speed up as each round progresses so that there is an increased difficulty and challenge for the player to deal with.
### Priority: **SHOULD**

## User Story 9:
#### As a player, I want a menu screen/pause option mid game so that I can pause my game if needed to while keeping my progress.
### Priority: **COULD**

## User Story 10:
#### As a player, I want the game to be online multiplayer so that I can play with my friend who is far away.
### Priority: **WONT**
