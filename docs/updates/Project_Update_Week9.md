### Challenges & risks (severity, mitigation)
- Implementation for variety game modes, as decision-making and implementing those into our game may require more time than we have. In order to nullify it, we have decided to split the tasks amongst our group.
- Time management, as we are nearing final exams, our schedules constantly change as a result, in order to spend more time on other course material. To help mitigate, stronger communication is required among our group members.
- Although not impossible, it is currently extremely difficult to score a point against the CPU so in order to mitigate this, we might have to make the CPU paddle move slower to make it harder for it to deflect the ball in time as its acceleration progresses.
- Since we want to implement themes/backgrounds, it might be difficult to allow players to change themes midway through the game so to mitigate this, allow players to restart the game through the pause menu option which allows them to reselect a theme. 
- Also want to include sound effects or maybe even animations into the game for user enjoyment which is confusing to implement right now, but can be mitigated by learning and watching tutorials for it!
